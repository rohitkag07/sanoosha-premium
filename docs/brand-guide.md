## Typography

| Role | Font | Weights | Usage |
|---|---|---|---|
| **Display / Headings** | Cormorant Garamond (serif) | 300, 400, 500, 600, 700, italic | H1, H2, section titles, product names, prices |
| **Body / UI** | DM Sans (sans-serif) | 300, 400, 500, 600 | Body text, nav, buttons, labels, tags |

**Google Fonts import:**
```
https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,300;0,400;0,500;0,600;0,700;1,400;1,600&family=DM+Sans:wght@300;400;500;600&display=swap
```

**Font Scale:**
- Hero H1: `clamp(2.8rem, 5vw, 4.5rem)` — Cormorant Garamond 600
- Section Title: `clamp(2rem, 4vw, 3.25rem)` — Cormorant Garamond 600
- Product Name: `1.1rem` — Cormorant Garamond 600
- Price: `1.4rem` — Cormorant Garamond 700
- Section Tag: `0.75rem` uppercase, letter-spacing 0.18em — DM Sans 600 (Gold color)
- Body: `1rem` — DM Sans 400
- Button: `0.875rem` uppercase, letter-spacing 0.06em — DM Sans 600
